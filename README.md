#  Full-Stack Blog Platform (MERN)

##  Project Overview

A full-stack blogging platform built using the **MERN stack (MongoDB, Express.js, React.js, Node.js)**. The platform allows users to read blogs and comment on posts, while **only the admin can create and manage blog content**. It also includes **AI-powered blog generation** to assist in content creation.

---

## 🚀 Features

###  User Features

* View and read blog posts
* Comment on blogs (login required)
* Secure authentication using **JWT**
* Clean and responsive UI

###  Admin Features

* Dedicated **Admin Panel**
* Create, update, and delete blog posts
* Generate blog content using AI
* Approve or reject user comments
* Full control over content and moderation
